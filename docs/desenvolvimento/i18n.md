# Internacionalização (i18n)

[← Índice](../README.md)

O frontend usa `i18next` + `react-i18next` com os idiomas `pt`, `en` e `es`.

## Como funciona

- Bootstrap em [`frontend/src/i18n/index.ts`](../../frontend/src/i18n/index.ts).
- Preferência: `localStorage` (`pdl.language`) → idioma do navegador → `pt`.
- Seletor: rodapé público, navegação e painel (`LanguageSwitcher`).
- Namespaces: `common`, `public`, `auth`, `panel`, `admin`, `help`.
- Formatação (`formatCurrency` / `formatDateTime`) acompanha o idioma ativo.

## Conteúdo da API

Passe `?lang=en` ou `?lang=es` (omitir = português). Superfícies cobertas:

- FAQ / handbook do Denkynho
- Notícias, wiki e roadmap
- Documentos legais
- Assistente (`language` no body)

Campos vazios na tradução pedida voltam ao português.

## CMS e admin

Modelos possuem campos `*_en` / `*_es` (FAQ, News, Wiki, Roadmap). O Jazzmin agrupa fieldsets EN/ES. Sem tradução automática: a equipe preenche ou usa o bootstrap EN→ES do FAQ.

## Adicionar strings na SPA

1. Inclua a chave nos três JSON em `frontend/src/i18n/locales/{pt,en,es}/`.
2. Use `useTranslation('namespace')` na tela.
3. Não reintroduza literais de UI nas superfícies já migradas (shell, FAQ, hub de relatórios).
